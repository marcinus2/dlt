## Decisions / deviations from plan

- **Clip is a 12 s loop, not 30 s with a pass every 4 s.** A 30 s 240×480 Y4M is ~155 MB; Chrome loops the file anyway. Uneven laps (4.5 / 3.0 / 4.5) make the best lap deterministic for flow 1.
- **Generator is `make-y4m.ts`, not `.mjs`**, so it reuses the seeded `syntheticClip` from the engine tests (run with `--experimental-strip-types`, like `parity`).
- **Fake-camera flags live on the `chromium` project**, so `--project=chromium` locally covers the real specs. `debug.spec.ts` dropped its own flags and now runs on the same clip.
- **`?cam=fake`, `?auto=0`, `?lap=` are sim-only**; sim e2e URLs gained `?sim=1`.
