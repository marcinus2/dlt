## Decisions / deviations from plan

- **`Effects` gained `platform: PlatformPort`** (`onVisibility`, `cameraPermission`, `unloadGuard`) and `wakeLock.onChange`; `src/platform/index.ts` builds the browser versions for both real and sim. **Sim mode now uses the real wake lock and visibility** (the sim log still shows wake-lock calls), so auto-pause can be tried in `?sim=1`.
- **Engine types**: `CameraError.blocked?` (permission only) and `CameraInfo.deviceFallback?`.
- **Portrait lock at boot, not per gesture**: the lock only works installed / fullscreen, where the manifest already locks on Android; trying it once is enough.
- **The unload guard follows "has data"** (spec §3.2), not "laps exist" (§3.4), so a running first lap also prompts. Paused with no laps doesn't prompt (the in-progress lap is already gone).
- **Headless Chromium rejects the real wake lock**, so the wake-lock banner appears in real/sim e2e sessions; specs that look for a banner filter by text. The wake-lock specs mock `navigator.wakeLock`.
