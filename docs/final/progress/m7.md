## Decisions / deviations from plan

- **PoC settings are migrated on every load until the first Save**, not copied into v2 at once: the spec writes v2 only on Save and leaves v1 alone. The PoC at `/poc/` shares the Pages origin, so a phone that used the PoC picks up its settings automatically.
- **Engine types gained `CameraDevice`, `ControlReport`** (moved from `camera-source.ts`) and `CameraInfo.label / exposure / focus`; `CameraPort` gained `listCameras` / `onDeviceChange`; `Effects` gained optional `diag` (real engine, analyzer and camera, plain references used only by the lazy Diagnostics chunk).
- **Calibrated ratios are clamped to the field ranges and rounded to 3 significant digits**, and end ≤ start, so a Calibrate result can always be saved.
- **Camera changes during a test apply on the next Start test** (said in the panel); live re-apply of exposure / focus isn't wired.
- **Diagnostics file replay uses its own `<video>`**; the single app `<video>` rule (iOS) is about the camera stream.
- **Two existing tests hardened**: `audio.spec.ts` lap-time regexes no longer assume sub-second laps (failed under parallel load), and the CPU-heavy `parity.test.ts` / `pipeline.test.ts` get a 20 s timeout (timed out under contention).
- **Overflow fix found by e2e**: a long camera label (Chrome's fake device) widened the Camera report and zoomed the page out on mobile; the report now wraps anywhere.
