## Decisions / deviations from plan

- **`PassEvent.t` added** (spec §5.2 type changed): the probe measures from the MOTION_END frame time, as the plan says, not from when the JS callback ran. Frame time is the `performance.now()` clock (`captureTime` / `now`), so it compares directly with `onstart`.
- **Effects.audio is the `Announcer`** (`unlock`, `cue(cue, lapMs, audio, onSpeechStart?)`, lock / voice listeners), not the earlier `{ unlock, cue }` stub. The runner passes the saved audio settings, so the reducer stays unaware of them.
- **Next-tap unlock lives in `unlock.ts`** (window capture listener, only while locked), so any tap re-enables sound, not only the banner button. The banner's button also calls `store.unlockAudio()`.
- **Diagnostics sound check and HUD land now** in the M2 Diagnostics placeholder (`?debug=1`). They move into the full Diagnostics panel in M7.5.
- **e2e (`audio.spec.ts`, Chromium, sim)** records `speechSynthesis.speak` / `cancel` and `createOscillator` via an init script: priming in GET READY and START, a tone with the context `running` for every cue, `cancel()` before every utterance, and the beep / voice / announceBest toggles. It can't check that sound is audible or how long speech takes; that is 6.7.
