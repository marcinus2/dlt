## Decisions / deviations from plan

- **Versions:** TypeScript **7.0** (native compiler; `tsc --noEmit` works as is), Vitest **5**, Biome **2.5**, Playwright 1.63, Tailwind 4.3, `@vitejs/plugin-react` 6. npm first picked vitest 3 (old vite 7 inside, audit warning), so it is pinned to `^5`.
- **`build` = `vite build` only** (no `tsc` in it), because CI already runs `typecheck` as its own stage. Added `build:poc` and `build:pages` (app + PoC in `dist/poc/`, exactly as deployed).
- **CI runs Playwright WebKit too**, not only Chromium as the plan says. Reason: WebKit can't run on the dev Mac (see Problems), so CI is the only place it runs. The PoC build happens before e2e, so e2e also checks `/poc/`.
- **CI layout:** jobs `poc` (tests), `app` (lint → typecheck → test --coverage → build:pages → size → e2e → Pages artifact unless PR), `deploy` (needs both; push to `main` or `workflow_dispatch`). Node version comes from `app/.nvmrc` (22).
- **Fonts:** own `@font-face` rules pointing at the fontsource **latin** woff2 files, instead of the packages' `index.css` (which pulls every subset). Inter 48 KB + JetBrains Mono 40 KB = 88 KB (≤ 100 KB budget).
- **Tailwind default palette disabled** (`--color-*: initial`), so only spec tokens exist (`bg-bg`, `text-text-muted`, `bg-accent`, …). Extra tokens: `text-lap-hero`, `text-lap-row`, `text-button`, `rounded-card`, `shadow-glow-{accent,danger,best}`; utilities `pt-safe`, `pb-safe`, `pb-safe-bar`, `px-safe`, `h-screen-d`/`min-h-screen-d`.
- **Boundaries go further than the plan:** `noRestrictedGlobals` blocks DOM globals in `engine/` outside `browser/` (`HTMLVideoElement` is left allowed for `FrameSource.video`), and `node:*` imports are blocked everywhere in `src/`. `zustand`, `motion` and `lucide-react` are also blocked in pure modules.
- **Boundary rules by folder depth in `ui/`:** Biome matches the import text, not the resolved path, so `../sim/x` is `ui/sim/` from `ui/screens/` but `src/sim/` from `ui/App.tsx`. Overrides exist per depth (0–3). Biome overrides replace rule options, so each file matches exactly one `noRestrictedImports` override. **When adding deeper `ui/` folders (> 3 levels), add an override.**
- **Vitest** uses inline `projects`: `unit` (node, `src/**/*.test.ts` outside `ui/`) and `ui` (happy-dom, Testing Library `cleanup` in `src/test/setup-ui.ts`). It reuses `vite.config.ts` (the `test` mode skips basic-ssl). No coverage thresholds yet; add the ≥ 90 % per-folder thresholds once those folders exist (M2).
- **Playwright** projects use `devices['Pixel 7']` (Chromium) and `devices['iPhone 15']` (WebKit) against `vite preview` on port 4173.
- **Manifest:** `public/manifest.webmanifest` with the spec §2.5 fields (`id`, `orientation: portrait`, `#0A0D12`). The PoC icons are copied to `public/icons/`, and `apple-touch-icon-180.png` was made with `sips`. It is replaced by `vite-plugin-pwa` in M9.
- **Build label** comes from `define` (`__APP_VERSION__` from package.json, `__GIT_SHA__` from `git rev-parse`, falling back to `GITHUB_SHA`, then `unknown`).
- `@testing-library/dom` is installed as an implicit peer of `@testing-library/react` (not listed in package.json).

## Problems

- **Local WebKit is broken on macOS 14 (Darwin 23):** Playwright installs a frozen WebKit that fails with `Unknown setting: PushAPIEnabled`. Locally use `npx playwright test --project=chromium`; WebKit runs in CI (Linux). This is also noted in CLAUDE.md.
- `git rm` of the only workflow deleted `.github/workflows/`; it was recreated (no impact).

## Ideas / notes for later milestones

- `★` (U+2605) is outside the latin subset and falls back to a system font. In M2 use a lucide icon for the best badge, or check the fallback glyph.
- The size script counts KiB (66.6), while Vite prints kB (69.1) for the same chunk. The budget uses KiB, which is slightly stricter.
- React alone is ≈ 67 KB gz, so there is ≈ 63 KB left for Motion (≈ 18), Zustand, lucide and app code in M2.
- The boundary checks were done by hand. If the rules change often, consider a script that lints known-bad fixture files.
- The PoC `/poc/` e2e test skips when `dist/poc` is missing (plain `npm run build`). Use `build:pages` before e2e to cover it.
